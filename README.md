# Trilingual Tamil Vocabulary Quiz App

A lightweight, interactive desktop application built using **Python** and **Tkinter** designed to help kids learn basic Tamil vocabulary through quiz-based gamification with **English** and **Sinhala** language interfaces.

---

## 🌟 Key Features

* **Dual Prompt Modes:** Choose between Sinhala and English interfaces for question prompts.
* **Dynamic Options Generator:** Generates 4 multiple-choice options dynamically without duplicate choices.
* **Unicode Font Rendering:** Built using Tkinter GUI to overcome native Windows CMD font-rendering issues for Sinhala & Tamil scripts.
* **Real-time Score Counter:** Instant score updates (`+10` points per correct answer) to encourage engagement.
* **Clean & Responsive Layout:** Simple card-style GUI tailored for kids.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **GUI Library:** Tkinter (Standard Python Library)
